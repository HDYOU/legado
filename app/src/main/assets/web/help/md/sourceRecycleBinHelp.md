# 规则回收站帮助

规则回收站会暂存被删除或被覆盖的书源、订阅源及各类规则，方便误操作后找回。默认保留 **7 天**，超期条目会在你打开回收站时自动清理。

---

## 开启与停用

顶栏「更多」菜单里可切换启用状态：

- **启用**（默认）：删除、覆盖等操作涉及的旧内容会先进回收站，再执行原操作。
- **停用**：回收站不再收录任何内容，删除 / 覆盖等于直接丢弃、不可找回。

---

## 哪些操作会进入回收站

| 操作                                                                                    | 进回收站的内容               |
| --------------------------------------------------------------------------------------- | ---------------------------- |
| 删除书源 / 订阅源 / 替换规则 / TXT 目录规则 / 在线朗读 / 字典规则 / 高亮规则 / 搜索引擎 | 被删除的那条本身             |
| 编辑保存时地址与另一条已存在的源相同，确认覆盖                                          | 被覆盖（顶替）的旧源         |
| 从回收站恢复一个源、遇到同地址源并选择覆盖                                              | 被顶替掉的、当前列表里的那条 |

> 覆盖的判定按**源地址**（书源 `bookSourceUrl` / 订阅源 `sourceUrl`），不是按名称。原地更新自己（未改地址）不会触发覆盖，也不会产生回收条目。

---

## 支持回收的类型

书源、订阅源、替换规则、TXT 目录规则、在线朗读规则、字典规则、高亮规则、搜索引擎。可用顶栏漏斗图标按类型筛选。

---

## 恢复

- 可单选或批量恢复，恢复条目从回收站移除、写回原列表。
- 恢复时若列表中已存在**同地址**（规则类为同主键）的内容，会弹出覆盖确认：
  - **同意覆盖**：用恢复的源替换掉现有源，被替换的那条先进回收站。
  - **取消**：不覆盖，该条保持留在回收站、跳过恢复。
- 不存在冲突时直接恢复，无需确认。

---

## 彻底删除与清空

- **彻底删除**：从回收站永久移除选中项，不可再找回。
- **清空**：「更多」菜单里的清空操作会移除回收站内的全部内容。

---

## 搜索

顶栏放大镜可搜索，匹配范围包括名称、地址 / 主键、分组，以及条目保存的原始 JSON 内容。
